# 连连看小游戏

这是一个纯前端实现的连连看小游戏，直接打开 `index.html` 即可游玩。

## 玩法
- 点击两张相同的卡片，若它们之间存在不超过两个拐点的连线即可消除。
- 通过“重新洗牌”打乱当前剩余卡片，或使用“重置关卡”重新生成全新棋盘。

## 本地运行
### 方式一：直接打开文件
在文件管理器中双击仓库根目录下的 `index.html`，即可在默认浏览器中游玩，无需额外依赖。

### 方式二：启动本地服务并访问地址
如果希望通过本地地址访问，进入项目根目录后运行：

```bash
python -m http.server 8000
```

然后在浏览器输入 `http://localhost:8000/index.html` 即可访问游戏页面。
